# 小帷 · 背景轻管家 (st-bg-lite)

SillyTavern 第三方扩展。接管背景面板和背景显示层，解决背景图一多就白屏的问题。

## 它做了什么

| 原生的问题 | 小帷的做法 |
| --- | --- |
| 背景列表一次性渲染全部图片，webp/avif 的"缩略图"其实是原图兜底，滑一下就爆显存 | 格子只是占位，进入视口才加载缩略图，离开视口立刻卸载；缩略图在本机生成一次后存进 IndexedDB |
| 切换时把原图直接塞给 `#bg1`，4K 图在显存里是 64MB | 上屏前先按当前屏幕尺寸缩放裁切（默认长边 2048），同样也缓存；旧图淡出后立即释放 |
| 每上传 / 删除一张就整体重建列表 | 走原生接口，列表增量更新 |

关掉设置里的"接管"开关，原生面板和原生背景层立刻恢复，不改动任何原生数据。

## 安装

方式一：手动放进扩展目录，刷新酒馆。

```
SillyTavern/data/default-user/extensions/st-bg-lite/
├── manifest.json
├── index.js
└── style.css
```

（旧版目录为 `SillyTavern/public/scripts/extensions/third-party/st-bg-lite/`。）

方式二：把这个文件夹推到一个 GitHub 仓库，酒馆里 扩展 → 安装扩展 → 粘贴仓库地址。

需要 SillyTavern 1.12 或更新（用了 `SillyTavern.getContext()`）。背景列表接口在酒馆 1.13.1 改过返回格式（1.16 起还带动图标记），小帷新旧格式都认。

## 使用

- 打开原来的背景面板（顶栏那个图片图标），现在里面是小帷的面板。
- 点格子即切换；格子右上角 `⋯`（电脑上右键）打开菜单：设为背景 / 锁定到本聊天 / 重命名 / 复制文件名 / 删除。
- 「批量」或长按任意格子进入多选，可全选、反选、批量删除。
- 排序可选名称或加入时间（最新在前 / 最旧在前）。新加的背景带 NEW 标，点一下就消失；工具栏出现「新 N」时点它可只看新的，再点「全部已看」一键清掉。加入时间用酒馆记录的（1.15+），老版本用本机第一次见到它的时间。
- 「上传」支持多选；默认会把长边超过 2560 或大于 1.5MB 的图压成 JPEG 再传（动图不压，视频见下面说明），可在设置里关。
- 「锁定到本聊天」把当前背景写进本聊天的元数据（原生的键和小帷的键一起写）。已经用原生锁定过的聊天会自动识别；生图插件的「设为聊天背景」、`/lockbg`、`/unlockbg` 这些走原生通道的操作，小帷也会跟着显示，哪怕图片不在背景库里。
- 斜杠命令：`/bglite 文件名`（支持部分匹配，无参数返回当前文件名）、`/bglite-lock`、`/bglite-unlock`；换了背景看不见时用 `/bglite-debug` 弹出排查信息、`/bglite-probe` 把显示层闪成粉色看它有没有被盖住。

设置在 扩展 面板里的「小帷 · 背景轻管家」：长边上限、适配方式、缩放质量、缩略图宽度与来源、格子大小、上传压缩参数、清缓存。

## 几点说明

- 缓存放在浏览器 IndexedDB，按设备各自生成；换设备或清浏览器数据后第一次打开会重建一遍，之后就快了。
- GIF / APNG / 动态 WebP 不做缩放，直接用原文件（否则会变静态）；上传时也会识别动图，不压缩。
- 酒馆的背景列表只收录图片，视频文件传上去不会出现在列表里。装了官方 [Video Background Loader](https://github.com/SillyTavern/Extension-VideoBackgroundLoader) 扩展后，小帷上传视频会和原生一样自动转成动态 WebP；没装会提示并跳过。
- 原生的「自动背景」功能被面板一起隐藏了；需要的话关掉接管开关再用。
- 没锁定时原生的 `/bg` 只改原生那层，小帷不跟；脚本里换背景请用 `/bglite 文件名`。
- 「同步到原生背景设置」默认关闭。开启后每次选择会额外调用原生 `/bg`，原生会多下载一次原图（不解码上屏），只为让原生设置文件里也记下当前背景。
